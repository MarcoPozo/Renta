# Renta

Marketplace de alquiler de objetos entre personas.

## Stack

- **Client:** React Native (Expo SDK 54)
- **Server:** Express (Node.js)

## Estructura

```
├── client/    # App móvil (React Native + Expo)
├── server/    # API REST (Express)
└── README.md
```

## Inicio rápido

### Server
```bash
cd server
npm install
npm run dev
```

### Client
```bash
cd client
npm install
npm start
```

### Probar en celular (iPhone)

1. Activar **hotspot WiFi** desde el PC
2. Conectar el iPhone al hotspot del PC
3. Escanear el QR con Expo Go
